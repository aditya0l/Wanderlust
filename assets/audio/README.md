# Music files

Put one licensed recording per place in this folder, then set its link in
Admin → Music (for example `assets/audio/ladakh.mp3`) and publish.

| Place | Track | Suggested file name |
|---|---|---|
| Ladakh | Baba Latifa (instrumental) | `ladakh.mp3` |
| Rajasthan (Jaipur, Golden Triangle) | Kesariya Banna (desi instrumental) | `rajasthan.mp3` |
| Dubai | Habibi Come to Dubai (Drinche ft. Dalvin) | `dubai.mp3` |
| South India (Kerala) | Vanchipattu (instrumental) | `southindia.mp3` |
| Himachal (Manali) | Pahadi dhun | `himachal.mp3` |
| Uttarakhand (Kumaon) | Kumaoni dhun (flute) | `uttarakhand.mp3` |
| Maldives | Generated sound, no file needed | — |

- Only use recordings you have the rights to: a purchased licence, a royalty-free
  version, or a recording you commissioned from local musicians.
- Keep each file short and light: a 60–90 second loop, MP3 at 128 kbps (about 1–1.5 MB).
- Places without a file keep playing their built-in generated sound.
